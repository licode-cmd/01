# ✦ OVERVIEW

**The Record Wall** is a creative front-end experiment that turns a simple record collection into an interactive 3D carousel.

Built with **no frameworks** — just HTML, CSS, and vanilla JavaScript — this project explores how far native web technologies can go when it comes to motion, 3D transforms, and tactile interaction.

<br>

> **Rigid geometry. Smooth motion. Pure vanilla.**
